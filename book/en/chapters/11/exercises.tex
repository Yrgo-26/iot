\exercise{Get the suite green}{Code}
\label{ex:11:1}
Add the supplied files unchanged and run them. Note how many test cases fail the first time.

Work through them one at a time, and keep a log:

\begin{narrowtable}{@{}llll@{}}
\thead{Test case} & \thead{What the name said} & \thead{Where the bug was} & \thead{Minutes} \\
\end{narrowtable}

The "minutes" column tends to fall dramatically as the exercise goes on, and the reason is that
you stop guessing.

\exercise{Which double catches what?}{Reasoning}
\label{ex:11:2}
For each one: \code{ScriptedTransport}, \code{BankTransport}, both, or neither? Justify in one
sentence, and \textbf{then check by introducing the bug}.
\begin{enumerate}[a)]
  \item \code{TX_DATA_LO} and \code{TX_DATA_HI} swapped.
  \item \code{clearError()} writes \code{0x1}.
  \item \code{receive()} does not mask against \code{dlc}.
  \item \code{receive()} forgets \code{RX_ACK}.
  \item \code{readReg()} counts the command byte's \code{MISO} answer.
  \item \code{send()} does not validate \code{dlc}.
  \item \code{MOSI} and \code{MISO} swapped in the wiring.
\end{enumerate}
Row g) is there for a reason. Which?

\exercise{Read the suite as a requirements specification}{Reasoning}
\label{ex:11:3}
Open the supplied \code{test_spi.cpp}.
\begin{enumerate}[a)]
  \item Which test case corresponds to the example \code{83 AA BB 00 00} in \kapref{ch:spi}?
  \item Which test case checks that an invalid frame costs not a single transaction? How does it
    check that?
  \item How many test cases use each double? Does the distribution match the reasoning in
    \secref{sec:twodoubles}?
\end{enumerate}

\exercise{The whole stack}{Code}
\label{ex:11:4}
Run the test case connecting \code{EchoNode} $\rightarrow$ \code{Spi} $\rightarrow$
\code{BankTransport}.
\begin{enumerate}[a)]
  \item How many lines have changed in \code{EchoNode} since \kapref{ch:komponent}?
  \item Which property of the architecture made the swap free?
  \item What would have had to change if \code{EchoNode} had taken a \code{driver::can::Spi&} in
    its constructor?
\end{enumerate}

\exercise{What remains}{Reasoning}
\label{ex:11:5}
Write a list of everything that can still be wrong even though the whole suite is green. Aim for
at least five points, of which at least one you found on your own.

The list is your checklist for \kapref{ch:bringup}.
