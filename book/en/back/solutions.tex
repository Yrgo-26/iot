\chapter{Solutions}
\label{ch:losningar}

Here are the solutions to \textbf{every exercise that does not ask for code} --- all the
reasoning, calculation and decoding exercises, and the parts of the coding exercises that are
reasoning. The solutions are complete: where an exercise asks for a calculation the steps are
there, and where it asks for reasoning the argument is there and not just the conclusion.

\textbf{The exercises that ask for code are not answered here.} For those, the supplied test suite
is the answer: it says, test case by test case, exactly what the code is to do. The code is also
published in the course repository after the lecture in question.

Read the solution after you have tried yourself. A solution you have read is not the same thing as
a solution you have arrived at, and that difference is what the exercises exist for.
